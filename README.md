# Looper

A browser-based loop pedal. Record from your mic, stack overdubs, play back in sync. No install, no plugins.

Live: https://binkpenguin.github.io/Looper/

## Controls

- Footswitch (or SPACE): arm, record, then overdub
- S: stop
- Z: undo last layer
- WAV: export the mix
- Latency comp: nudge in ms if layers land late

## Notes

- Needs mic permission, so it only runs over HTTPS (GitHub Pages provides that)
- Use headphones. Monitoring through speakers bleeds into new layers.
- Everything runs client-side. Nothing is uploaded.
